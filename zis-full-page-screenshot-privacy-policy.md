# ZiS - Full Page Screenshot — Privacy Policy

**Effective Date:** September 3, 2026
**Last Updated:** September 3, 2026

## 1. Introduction

ZiS - Full Page Screenshot ("the Extension") is a Chrome browser extension developed by **Ziscom** that allows users to capture complete webpages, including content that extends beyond the currently visible browser viewport.

This Privacy Policy explains what information the Extension accesses, how it is used, and how it is handled.

## 2. Information and Data We Handle

The Extension may temporarily access **website content** from webpages when the user explicitly starts a screenshot capture. This may include webpage text, images, and other visual content that is necessary to create the requested screenshot.

The Extension does **not** collect or intentionally request:

* Name, address, email address, or other personally identifiable information
* Health information
* Financial or payment information
* Passwords or authentication information
* Personal communications
* Precise location information
* Browsing history for tracking or analytics purposes
* Keystrokes, mouse activity, or other activity for tracking purposes

## 3. How Website Content Is Used

Website content is accessed solely to provide the Extension's full-page screenshot functionality.

When a user starts a screenshot:

1. The Extension accesses the selected webpage.
2. It captures the required portions of the webpage.
3. The captured portions are processed and combined into the final screenshot.
4. The resulting screenshot can be saved to the user's device.

Website content is not collected for advertising, profiling, analytics, or unrelated purposes.

## 4. Local Processing

Screenshot processing is performed within the user's browser whenever possible.

The Extension does not operate a server that receives or stores the webpages or screenshots captured by users.

Captured webpage content is not intentionally transmitted to Ziscom's servers.

## 5. Downloads

The Extension may use Chrome's download functionality to save a screenshot to the user's computer when the user chooses to save or download the captured image.

Downloads are initiated as part of the screenshot functionality and are not used to download unrelated content.

## 6. Storage

The Extension may use Chrome's local extension storage to remember user preferences and settings.

Stored information is limited to Extension settings and preferences. The Extension does not use storage to build a browsing-history database or user profile.

## 7. Browser Permissions

The Extension may request browser permissions such as:

* **Host permissions:** to access webpages selected by the user for screenshot capture.
* **Scripting:** to execute the screenshot functionality on the selected webpage.
* **Tabs:** to identify and interact with the active tab during screenshot capture.
* **Downloads:** to save screenshots to the user's device.
* **Storage:** to remember Extension settings.
* **Offscreen:** to perform image-processing operations that require browser APIs unavailable to the Manifest V3 service worker.
* **Notifications:** to provide screenshot-related status or error notifications when necessary.

These permissions are used only to provide the Extension's stated screenshot functionality.

## 8. Remote Code

The Extension does not intentionally load or execute remotely hosted executable code.

The JavaScript required for the Extension's functionality is included in the Extension package.

## 9. Data Sharing and Sale

Ziscom does **not sell user data**.

Ziscom does not transfer website content accessed by the Extension to third parties for advertising, profiling, or other purposes unrelated to the Extension's single purpose.

## 10. Advertising and Analytics

The Extension does not use website content captured through the screenshot functionality for targeted advertising or user profiling.

## 11. Children's Privacy

The Extension is not specifically directed toward children, and it does not knowingly collect personally identifiable information from children.

## 12. Data Security

We take reasonable measures to limit the handling of information accessed by the Extension to what is necessary to provide its functionality.

Because screenshot processing occurs in the user's browser, users should understand that the resulting screenshots are under their control and may contain information displayed on the webpage they choose to capture.

## 13. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes to the Extension, its functionality, or applicable requirements.

The latest version will be published in this repository.
